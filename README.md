## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/blackrainbowtest/painting_brushes.git
   ```

2. **Browse the collection** and pick the brushes that suit your project.

3. **Import** the brush files into your favourite painting application (e.g. Procreate, Photoshop, Krita, etc.).
